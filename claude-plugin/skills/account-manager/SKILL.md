# Account Manager

Manage YouTube and Twitter accounts in MoneyPrinterV2's cache.

## Cache Files

- YouTube: `.mp/youtube.json`
- Twitter: `.mp/twitter.json`

## Listing Accounts

```bash
cd /home/user/MoneyPrinterV2
python claude-plugin/scripts/list-accounts.py --provider youtube
python claude-plugin/scripts/list-accounts.py --provider twitter
```

Or read the cache file directly:
```bash
cat .mp/youtube.json | python -m json.tool
```

## Adding a YouTube Account

```bash
cd /home/user/MoneyPrinterV2
python claude-plugin/scripts/manage-account.py add --provider youtube \
  --nickname "My Channel" \
  --firefox-profile "/path/to/firefox/profile" \
  --niche "cooking tips" \
  --language "English"
```

### YouTube Account Schema
```json
{
  "id": "<auto-generated UUID>",
  "nickname": "My Channel",
  "firefox_profile": "/path/to/firefox/profile",
  "niche": "cooking tips",
  "language": "English",
  "videos": []
}
```

## Adding a Twitter Account

```bash
cd /home/user/MoneyPrinterV2
python claude-plugin/scripts/manage-account.py add --provider twitter \
  --nickname "My Bot" \
  --firefox-profile "/path/to/firefox/profile" \
  --topic "tech news"
```

### Twitter Account Schema
```json
{
  "id": "<auto-generated UUID>",
  "nickname": "My Bot",
  "firefox_profile": "/path/to/firefox/profile",
  "topic": "tech news",
  "posts": []
}
```

## Removing an Account

```bash
cd /home/user/MoneyPrinterV2
python claude-plugin/scripts/manage-account.py remove --provider youtube --account-id <UUID>
```

## Important Notes

- The `firefox_profile` path must point to an existing Firefox profile directory
- The profile must be **pre-authenticated** to the target platform
- Account UUIDs are auto-generated and used throughout the system
- Removing an account also removes its cached videos/posts history
